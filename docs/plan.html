Minimal Spotify client

Electron, React, shadcn/ui, Tailwind 4, Motion. Plan agreed 2026-10-19.

Decisions

QuestionAnswer
PlaybackRemote control over Spotify Connect. The official app or another device plays audio; this app controls it through the Web API.
WindowNormal window: hover-expand icon rail for the library, content area, persistent player bar. Closes to tray; the official Spotify app runs hidden.
Package managerBun

Why remote control

The Web Playback SDK needs Widevine and Spotify supports it in browsers only. Electron attempts, including the castLabs Widevine build, report cut-offs after about 30 seconds and license-server errors. Remote control is reliable now. In-app audio stays a separate experiment.

Platform limits (February 2026 Dev Mode changes)

  • The app owner needs Premium, and each app is capped at 5 users. That's fine for a personal client.
  • You can only read items in playlists you own or collaborate on.
  • Recommendations, audio features and featured playlists are gone, so there is no Home feed.

Architecture

  • Auth: PKCE in the main process (src/main/auth.ts) with the loopback redirect http://127.0.0.1:8888/callback. The refresh token is encrypted with safeStorage. The renderer only gets short-lived access tokens over IPC.
  • Data: plain fetch to api.spotify.com (lib/spotify.ts). Playback state is polled every 1.5 s while the window is visible, and progress is interpolated locally (lib/player.ts).
  • UI: customised shadcn Button and Slider. No router or state library: a view state plus a back stack covers it.

Design direction

  • Near-black surface, high-contrast text, Segoe UI Variable.
  • Signature element: album art supplies the only accent colour, used for the scrubber, focus rings and a faint background wash.
  • Motion is limited to a shared-layout expand from the player bar to full now-playing, plus an art cross-fade on track change. Both honour reduced motion.

Running it

  1. Create an app at developer.spotify.com/dashboard with redirect URI http://127.0.0.1:8888/callback and the Web API enabled.
  2. Copy .env.example to .env and set MAIN_VITE_SPOTIFY_CLIENT_ID.
  3. Run bun run dev.
