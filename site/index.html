What you need

The Spotify app for Windows and a Premium account. MusicThing signs in to Spotify once and remembers you.

Installing

The installer isn't signed yet, so Windows may stop it. Choose More info, then Run anyway.

Updates

New versions download in the background and install the next time you quit.
